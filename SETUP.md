# SMG CRM — First-Run Setup

Run these steps **once** to get the app running locally on your Mac. Approximate time: 10 minutes.

---

## 1. Install Postgres (easiest path — Postgres.app)

You don't have Docker or Homebrew on this machine, so the easiest option is **Postgres.app**.

1. Download Postgres.app from https://postgresapp.com (grab the **Universal** build that includes Postgres 16).
2. Drag `Postgres.app` into `/Applications`.
3. Open the app. Click **Initialize** to create a server on port `5432`.
4. In the Postgres.app window, click the **hat** icon → **Server Settings** → leave defaults. The default user on your Mac will be created automatically (matches your macOS username).

**Optional but recommended:** add the Postgres.app CLI tools to your path so `psql`, `createdb`, etc. work in any shell:

```bash
sudo mkdir -p /etc/paths.d && \
  echo /Applications/Postgres.app/Contents/Versions/latest/bin | \
  sudo tee /etc/paths.d/postgresapp
```

Restart your terminal, then verify:

```bash
psql --version
```

---

## 2. Create the database

Postgres.app's default user is your macOS username (`titiusmclaughlin`) with no password. Create a database for the CRM:

```bash
createdb smg_crm
```

If the command above isn't available (step 1 optional part not done), open Postgres.app → double-click the `postgres` database to open `psql`, then run:

```sql
CREATE DATABASE smg_crm;
```

---

## 3. Configure environment variables

From inside `smg-crm/`:

```bash
cp .env.example .env
```

Edit `.env`:

- **`DATABASE_URL`** — update username if needed. For Postgres.app (no password, user = macOS username):
  ```
  DATABASE_URL="postgresql://titiusmclaughlin@localhost:5432/smg_crm?schema=public"
  ```
- **`AUTH_SECRET`** — generate one:
  ```bash
  openssl rand -base64 32
  ```
  Paste the output. This is what NextAuth uses to sign session tokens.
- **Seed passwords** — change `ChangeMeOnFirstLogin!` to something you'll remember for your first login (you can change it later in-app once auth UI is added). The seed script sets these for Titius, Matthew, and Peter. They are skipped on re-seed so you can change them.

You can leave Twilio / SendGrid / S3 / Redis blank. Those are wired up in Phase 1C.

---

## 4. Install deps and migrate

```bash
pnpm install
pnpm approve-builds    # pick prisma, @prisma/engines, esbuild
pnpm prisma migrate dev --name init
pnpm db:seed
```

If `prisma migrate dev` complains about connectivity, double-check:
- Postgres.app shows a green "Running" indicator.
- `psql -d smg_crm -c 'SELECT 1'` returns a `1`.
- The user in `DATABASE_URL` matches your macOS username.

## Troubleshooting

**`Error: P1001: Can't reach database server`** — Postgres.app isn't running. Open the app and click the start button.

**`Error: P3014: Prisma Migrate could not create the shadow database`** — Your Postgres user needs `CREATEDB` privilege. In `psql`:
```sql
ALTER USER titiusmclaughlin CREATEDB;
```

**Invite link works but login fails** — The accept-invite page sets the password; once set, sign in at `/login` with that email + new password.

**CSV import hangs on a very large file** — we parse client-side to raw rows then stage server-side in chunks of 500. 10–20K rows should finish in under a minute. For much larger files we can switch to streaming (deferred until needed).

**Commands don't work in the folder name with spaces** — the folder path contains spaces, which is fine for Next.js / Prisma / pnpm. Just use `cd` with quotes:
```bash
cd "/Users/titiusmclaughlin/Desktop/Solar Maintenance Guys/AI Stuff/Sales Management CRM/smg-crm"
```
